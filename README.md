Frontend:
- React 18
- TypeScript
- SCSS Modules
- Material UI
- Context API

Backend:
- NestJS
- PostgreSQL
- JWT
- bcrypt


### Архитектура и производительность
```markdown
- TypeScript для типизации 
- API для глобального состояния
- Кастомные хуки для переиспользуемой логики
- Оптимизация рендеринга с React.memo
- Адаптивный дизайн с SCSS модулями
```

### Продвинутые фичи
```markdown
- Кастомный аудио плеер с прогресс-баром
- Визуализация треков в реальном времени
- Система поиска и фильтрации
- JWT авторизация
- Система управления плейлистами
```


### Безопасность и интеграция с бэкендом
```markdown
- JWT-авторизация с защитой роутов
- Хеширование паролей через bcrypt
- Защищенные API эндпоинты
- Обработка ошибок и валидация
```
